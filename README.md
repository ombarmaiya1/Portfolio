# Om Barmaiya Portfolio

A responsive React + Vite personal portfolio starter, using the supplied portrait.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
npm run preview
```
